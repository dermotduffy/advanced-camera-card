# Agent documents

Written for AI agents working on this project.

| Folder                                | For                                      | Contents                                               |
| ------------------------------------- | ---------------------------------------- | ------------------------------------------------------ |
| [`standards/`](standards/)            | Any agent writing code for this project  | The review rubric and the writing standard.            |
| [`maintainer/`](maintainer/README.md) | Agents acting on the maintainer's behalf | The implement loop being trialed, and decision rights. |

Agents that do not act for the maintainer follow `standards/` and must not take
the actions described in `maintainer/`, such as posting in the maintainer's
name.
