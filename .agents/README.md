# Agent documents

Written for AI agents working on this project. If you use the card, see
[How AI is used](https://card.camera/#/ai) instead.

| Folder                                | For                                      | Contents                                                                                                              |
| ------------------------------------- | ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| [`standards/`](standards/)            | Any agent writing code for this project  | Hard rules, the review rubric, the writing standard, and the change classes every PR is labeled with.                 |
| [`maintainer/`](maintainer/README.md) | Agents acting on the maintainer's behalf | How the maintainer's agents operate: roles, decision rights, triage, releases, replies to users, and contributed PRs. |

Agents that do not act for the maintainer follow `standards/` and must not
take the actions described in `maintainer/`, such as labeling issues, replying
to users or posting in the maintainer's name.
